# Boss portrait art (hand-drawn only!)
Drop PNGs here and the boss uses them automatically (no code changes):
`portrait_idle.png`, `portrait_smug.png`, `portrait_angry.png`, `portrait_squashed.png`, `portrait_enraged.png`, `portrait_defeated.png`.
Square, e.g. 64x64. Draw in Piskel (free, in the browser: piskelapp.com), Aseprite or LibreSprite.
Make an ORIGINAL character (no GTA / Rockstar characters). Missing files fall back to the placeholder slime face.
